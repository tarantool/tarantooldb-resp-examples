# Примеры Tarantool Database (RESP)

В этой ветке репозитория собраны запускаемые Docker-примеры для Tarantool Database (RESP) 2.x. Каждый пример — это
самостоятельный стенд с файлами конфигурации и файлом `README.md`,
содержащим пошаговую инструкцию.

Чтобы запустить пример, перейдите в директорию этого примера и выполните следующую команду:

```shell
make start
```

Для остановки стенда выполните команду ниже:

```shell
make stop
```

Подробности работы приведены в `README.md` соответствующего примера. Для работы примеров требуются
установленный Docker-образ Tarantool Database (RESP) и приложение Docker Compose; для проверки
работы кластера дополнительно может понадобиться утилита `redis-cli`.
